## 📖 Sobre el curso

Mi nombre es **Sadan De la Cruz**, docente del Departamento de Economía de la Universidad de Pamplona, Colombia. Esta asignatura brinda las herramientas necesarias para analizar datos económicos de manera científica y rigurosa.

El curso está diseñado para estudiantes de **pregrado** e integra teoría económica, estadística y matemática para desarrollar métodos que te proporcionen herramientas estadísticas inferenciales básicas, permitiéndote plantear, resolver e interpretar problemas reales apoyado en software estadístico.

A lo largo del curso usamos diferentes fuentes de datos económicos para ofrecer ejemplos prácticos. Buscamos armonizar la teoría y la práctica —el punto donde más dificultades suelen presentar los estudiantes— con una base sólida en métodos cuantitativos y aplicación real a través de software estadístico.

## 🎯 Objetivos del curso

Al finalizar el curso, serás capaz de:

- Resolver problemas relativos a las probabilidades elementales.
- Aplicar las diferentes distribuciones de probabilidad como modelos de fenómenos probabilísticos.
- Definir una hipótesis y probarla con las teorías necesarias.
- Describir el procedimiento de prueba de hipótesis en cinco pasos.
- Distinguir entre pruebas de hipótesis de una y dos colas.
- Llevar a cabo una prueba de hipótesis para una media poblacional.
- Realizar de manera adecuada un análisis exploratorio de datos.
- Construir modelos que representen adecuadamente situaciones reales.
- Realizar la inferencia asociada a los modelos construidos.
- Presentar los elementos básicos para el análisis exploratorio de datos.
